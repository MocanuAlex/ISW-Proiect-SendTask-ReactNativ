SendTask este o aplicație mobilă construită cu React Native și Firebase, dedicată managementului sarcinilor în echipe mici
printr-un sistem ierarhic de delegare bazat pe roluri (Admin, Manager, Utilizator). Pe lângă coordonarea eficientă a taskurilor,
aplicația integrează notificări în timp real, un modul  pentru productivitate și statistici vizuale ale activității.
